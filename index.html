How a Command Reaches the Device

The generator listens for a short text command over the network. Unity, Unreal, the control app, and the C++/Java samples in the manual all send the same format.

1

Something happens in the scene

An event in the VR or AR experience — entering a room, a fire breaking out — decides it's time for a scent.

2

A command goes out

A UDP message names the port, the intensity, and how long the fan should run for.

3

The cartridge sprays

The matched cartridge releases into the airflow, and the fan clears whatever scent was there before.

4

It reaches the room

Across the generator's 30 m² coverage, the scent lands in sync with the sound and visuals.

OUT,[port 01–10],[intensity 0100–0500],1,[fan time 1000–9000 ms],1000

The two fixed fields in the middle and at the end are internal — the manual notes they shouldn't be changed.

Triggering It From Node.js

The manual only shows C++ and Java samples. Here's the same UDP message in JavaScript, using Node's built-in dgram module. It runs as a small standalone script, not inside a browser — browsers can't open raw UDP sockets, which is also why the ports above only simulate the command rather than firing it.

const dgram = require('dgram'); const socket = dgram.createSocket('udp4'); const DEVICE_IP = '192.168.0.40'; // the generator's address on your network const DEVICE_PORT = 8000; // confirm against your PacketSender export function activateScent(port, intensity = 100, fanMs = 2000) { const message = [ 'OUT', String(port).padStart(2, '0'), String(intensity).padStart(4, '0'), '1', String(fanMs).padStart(5, '0'), '1000' ].join(','); socket.send(message, DEVICE_PORT, DEVICE_IP, function (err) { if (err) console.error('Send failed:', err); else console.log('Sent:', message); }); } activateScent(2, 150, 3000); // Fire and Explosions, medium intensity, 3s

The UDP port isn't printed as plain text in the guide — pull it from the PacketSender export file the manual links to, or confirm it with Olorama support.
